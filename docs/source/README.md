# Historical Sources and Backups

This folder holds source documents and snapshots for reference only. They are
not the current game plan; prefer the current docs linked from
[`../PROJECT_MEMORY.md`](../PROJECT_MEMORY.md).

## Contents

- `ORIGINAL_GAME_DESIGN.txt` and the adjacent DOCX/PDF files: supplied
  historical design documents. Their scope may conflict with current
  decisions.
- `PALM_ISLAND_GAME_PLAN_EARLY_DRAFT.md`: an earlier plan, retained for
  provenance.
- `archives/`: planning ZIPs and patch snapshots. Do not apply a patch
  automatically; inspect it against the current branch first.
- `backups/`: preserved uploads and prior document snapshots, grouped by
  narrative, design, asset-pack notes, and movement prototype.

Some files under `backups/` are byte-identical to their counterparts in the
parent folder. They are retained as source snapshots, not active duplicate
documents; edit the active files only.
