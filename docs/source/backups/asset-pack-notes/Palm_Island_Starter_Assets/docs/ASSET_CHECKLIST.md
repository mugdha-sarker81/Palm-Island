# Palm Island — Forgotten Jungle Asset Checklist

## Required for the first playable slice

### Player: Ichigo
- [ ] Idle animation (4–6 frames)
- [ ] Run animation (6–8 frames)
- [ ] Jump and fall frames
- [ ] Sword/dagger attack animation
- [ ] Hurt and death animation
- [ ] Dodge/roll animation

### Environment / tileset
- [ ] Grass top, dirt middle, dirt bottom tiles
- [ ] Left/right edges and inner/outer corners
- [ ] One-way platforms and ledges
- [ ] Cliffs and cave entrance
- [ ] Background layers: distant jungle, midground trees, foreground foliage
- [ ] Vines, bushes, flowers, mushrooms, rocks, fallen logs
- [ ] Bridge and climbable vine/ladder if used
- [ ] Thorn barrier that can be cut with Thornfang

### Gameplay props
- [ ] Chest: closed/open states
- [ ] Clue: Map of Roots (world item + inventory icon)
- [ ] Checkpoint / save shrine
- [ ] Breakable object
- [ ] Puzzle switch and gate
- [ ] Health pickup and simple collectible

### Enemies / boss
- [ ] Small jungle enemy: idle, move, attack, hurt, death
- [ ] Thornback guardian: idle, walk, attack, wind-up, hurt, defeat
- [ ] Telegraph effects for boss attacks

### Weapons / effects
- [ ] Starter sword or dagger icon
- [ ] Thornfang weapon icon and world pickup
- [ ] Slash arc, hit spark, dust puff, damage flash
- [ ] Pickup glow and clue-discovery effect

### UI
- [ ] Health bar / hearts
- [ ] Equipped weapon icon
- [ ] Interaction prompt
- [ ] Clue notification
- [ ] Pause menu and inventory panel
- [ ] Boss health bar

### Audio (not included in this image pack)
- [ ] Footsteps, jump, land, attack, hit, hurt, death
- [ ] Chest open, item pickup, clue found, switch/gate
- [ ] Jungle ambience and short music loop

## Suggested first-pass technical conventions
- Pick one tile size and use it consistently in each tileset.
- Keep gameplay sprites at a consistent pixel density; avoid mixing tiny pixel sprites with high-resolution painted assets.
- Export sprites on transparent backgrounds and keep animation frames aligned to a shared baseline.
- Store an attribution/license note beside each third-party pack.
