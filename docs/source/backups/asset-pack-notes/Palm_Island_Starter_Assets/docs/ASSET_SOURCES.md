# Suggested third-party asset sources

These are curated source links, not bundled third-party downloads. Review the current license and pack contents before use.

1. **Kenney — Pixel Platformer**
   - URL: https://kenney.nl/assets/pixel-platformer
   - Source page states: CC0; 18×18 tile size; 200+ files. Good for quick prototype tiles, props, characters, and enemies. Style is simpler than anime-inspired art, so use consistently or as a temporary prototype set.

2. **Kenney — New Platformer Pack**
   - URL: https://kenney.nl/assets/new-platformer-pack
   - Source page states: CC0; 440+ files. Review its style and contents before combining with another pack.

3. **OpenGameArt — OPP Jungle Tiles**
   - URL: https://opengameart.org/content/opp-jungle-tiles
   - License shown on the source page: CC-BY 3.0. Includes jungle terrain and objects. Attribution is required; the page asks users to credit all contributors. Read the page before shipping.

4. **Kenney — Pixel Platformer Blocks**
   - URL: https://kenney.nl/assets/pixel-platformer
   - The linked Pixel Platformer page also lists related block expansions. Check the specific pack's license and files before downloading.

## Recommendation
For the first prototype, pick **one consistent art style**. Use the concept sheet as a target for the Forgotten Jungle mood, then either adapt one licensed tileset consistently or commission/create a unified set of player, enemy, boss, and environment sprites. Avoid mixing assets with noticeably different pixel scales.
