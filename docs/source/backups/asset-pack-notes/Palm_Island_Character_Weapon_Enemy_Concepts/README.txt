PALM ISLAND - PLAYER, WEAPONS & ENEMIES CONCEPT PACK

Contents:
- Player_Weapons_Enemies_Concept_Sheet.png

The PNG is a 1536x1024 concept-art reference board showing:
- Ichigo player design and example animation poses
- Five legendary weapons: Thornfang, Embercleaver, Stormpiercer, Dawnstring, Voidfang
- Enemy and guardian concepts, including Thornback
- Extra props such as treasure, clues, checkpoints, switches, gates, and UI ideas

IMPORTANT:
This is a concept/reference sheet, not a production-ready sprite atlas. The illustrations are not individually exported transparent sprites and should not be sliced blindly for animation. For Raylib, prepare separate transparent PNG spritesheets with consistent frame dimensions, animation rows, and documented frame coordinates. Check any third-party assets' license before shipping the game.
