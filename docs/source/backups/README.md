# Design and Story Source Backups

This folder contains recoverable snapshots of the original story, character/game-design, planning, and asset-source notes. The active working copies remain in `docs/` and `docs/source/`; do not edit backup snapshots as the canonical versions.

## Backup contents

- `narrative/` — copies of the narrative design and original game-design DOCX/PDF files.
- `design/` — copies of the original design text, current and earlier plans, level design, decisions, and asset index.
- `asset-pack-notes/` — extracted README, checklist, and source/license notes from the bundled asset packs.

The original asset ZIPs are preserved in `assets/source_packs/`, and the original planning ZIP is preserved in `docs/source/archives/`.

## Prompt files

No standalone prompt-named text files were present in the project when this backup was made. Text notes found inside the asset archives have been copied to `asset-pack-notes/`. If separate story or image-generation prompt files are added later, copy them here before editing and record their original path.
